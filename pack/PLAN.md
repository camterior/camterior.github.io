# 캠핑 챙김 계획

> 작업할 때마다 이 파일을 먼저 읽고, 단계가 끝나면 아래 [진행 순서]에 완료 표시를 합니다.

## 무엇을 만드나
- 캠테리어 저장소 안 `/pack` 경로에 만드는 모바일용 장비 체크리스트 앱
- 음식 기능 없음, 캠핑 장비만
- 캠테리어에 등록한 "내 장비"를 불러오고, 챙김에서도 장비 등록 가능
  (두 곳이 같은 장비 목록을 함께 씀)
- AI 추천은 내 장비 목록 안에서만 고름. 꼭 필요한데 없는 장비는
  "없음(대여·대체 가능)"으로 따로 작게 표시
- 날씨(기온), 바닥(데크/파쇄석), 환경(계곡/바다/산)을 고려
- 캠핑 당일 체크 안 된 장비가 있으면 푸시 알림
- 안드로이드·아이폰 모두 홈 화면 설치형 앱(PWA)

- 내가 승인하면 main에 합치고 푸시

## 조사 결과 (1단계)
- 기기 안: 브라우저 localStorage의 `camMine` 키 (`src/mine.js`)
- 서버: Cloudflare Worker KV(`RL`)의 `acct:<내 코드>` 키 (`worker/worker.js`의 `acct()`)
  - 내 코드는 기기 localStorage `camAcct`에 보관, 형식 `XXXX-XXXX`
  - 읽기 `{acct:{op:'get',code}}`, 저장 `{acct:{op:'save',code,gear}}`, 새 코드 `{acct:{op:'new'}}`
  - 페이지를 열면 서버 장비가 있으면 서버 쪽이 우선, 없으면 기기 것을 올림
- 형식: `{"분류:장비번호": 개수}` 예) `{"gear:sc25": 2, "chair:sp_fd": 4}`
  - 개수 1~20, 최대 300종, 키 모양 `^[a-z]+:[a-z0-9_]{1,40}$`만 저장됨
  - 이름·제원은 저장하지 않음 → 캠테리어 카탈로그에서 찾아서 표시
- 서버 계정 전체: `{gear, vip, admin, at, up}` (개인정보 없음)

## 2단계 메모
- 화면: `pack/index.html`, `pack/pack.js`, `pack/pack.css`
- 장비 목록(이름·분류·사진 여부): `pack/catalog.json` — 캠테리어에서 뽑아 만든 파일.
  캠테리어에 장비를 새로 넣으면 `node scripts/pack-catalog.js`로 다시 만들어야 챙김에도 나옴.
- 목록에 없는 장비(직접 넣기): 같은 목록에 `my:<8글자>` 키로 개수, 이름·분류는 localStorage `camMineCustom`
  = `{id:{n:이름, c:분류}}`, 서버는 save의 `custom`으로 저장(워커 수정, main 합칠 때 배포됨).
  분류: tent, table, sleep, light, heat, kitchen, store, tool, etc
- 캠테리어 화면은 `my:` 장비를 안 보여주고, 개수·'내 장비만 보기' 숫자에서도 뺌 (`src/mine.js`, `index.html`).
- 루트 서비스워커(`sw.js`)는 `/pack/`을 건드리지 않음 → 5단계(PWA)에서 챙김 전용으로 따로 만들기.
- 배포 검사(`scripts/smoke.js`)에 챙김 화면 확인 추가. 배포 파일 목록(`deploy.yml`)에 pack 추가.
- 파일을 고치면 `index.html`의 `pack.css?v=`·`pack.js?v=`·`trips.js?v=` 숫자를 올리기 (안 올리면 브라우저가 옛 파일을 써서 화면이 비어 보일 수 있음).

## 3단계 메모
- 화면 3개(주소): `#` 캠핑 목록 · `#t/<id>` 캠핑 하나(체크하기/장비 고르기) · `#gear` 내 장비함. 코드: `pack/trips.js`
- 캠핑 저장: localStorage `packTrips` = `[{id, name, date:'YYYY-MM-DD', nights, place, items:{장비키:가져갈 개수}, done:{장비키:1}, at}]`
  아직 **이 기기에만** 저장 → 6단계(로그인·동기화)에서 서버로.
- 새 캠핑의 장비: 빈 목록 / 내 장비 전부 / 지난 캠핑 목록 그대로(체크는 새로) 중 고름.
- 4단계(AI)에서 쓸 날씨·바닥·환경 칸은 아직 없음 → 4단계에서 캠핑 만들기 창에 추가.
