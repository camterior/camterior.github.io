## 조사 결과 (1단계)
- 기기 안: 브라우저 localStorage의 `camMine` 키 (`src/mine.js`)
- 서버: Cloudflare Worker KV(`RL`)의 `acct:<내 코드>` 키 (`worker/worker.js`의 `acct()`)
  - 내 코드는 기기 localStorage `camAcct`에 보관, 형식 `XXXX-XXXX`
  - 읽기 `{acct:{op:'get',code}}`, 저장 `{acct:{op:'save',code,gear}}`, 새 코드 `{acct:{op:'new'}}`
  - 페이지를 열면 서버 장비가 있으면 서버 쪽이 우선, 없으면 기기 것을 올림
- 형식: `{"분류:장비번호": 개수}` 예) `{"gear:sc25": 2, "chair:sp_fd": 4}`
  - 개수 1~20, 최대 300종, 키 모양 `^[a-z]+:[a-z0-9_]{1,40}$`만 저장됨
  - 이름·제원은 저장하지 않음 → 캠테리어 카탈로그에서 찾아서 표시
- 서버 계정 전체: `{gear, vip, admin, at, up}` (개인정보 없음)

## 6단계 메모
- 로그인 = 캠테리어와 같은 **'내 코드'** (개인정보 없음). 장비를 넣거나 캠핑을 만들면 자동으로 생김. 다른 기기는 내 장비함 아래에서 코드 넣기.
- 서버: 워커 `acct` `op:'trips'`(읽기) / `op:'trips_save'`(합쳐서 저장), KV 키 `trips:<코드>`, IP당 하루 600번 저장.
- 합치는 규칙(서버 `worker.js`와 화면 `trips.js`의 mergeTrip이 같음):
  - 이름·날짜·며칠·장소·고른 장비 → `mu`(고친 시각)가 늦은 쪽
  - 체크 → 장비마다 `dt[장비키]`(누른 시각)가 늦은 쪽 → 두 사람이 다른 폰으로 같이 체크해도 안 사라짐
  - 지운 캠핑 → `{id, del:1, up}`을 60일 남김 (다른 기기에서 다시 살아나지 않게)
- 이 기기 저장: `packTrips`, `packTripsDel`(지운 것), `packTripsCode`(어느 코드의 목록인지), `packTripsDirty`(못 보낸 변경 있음)
- 언제 맞추나: 앱 열 때, 다시 화면으로 돌아올 때(20초에 한 번까지), 인터넷 다시 연결될 때, 고친 뒤 1.5초.
- 코드를 바꿔 불러오면 이 기기 목록을 그 코드 것으로 바꿈(다른 사람 일정 섞이지 않게).
- Cloudflare KV는 지역마다 반영이 최대 1분쯤 늦을 수 있음 → 다른 기기에서 바로 안 보이면 잠시 뒤 다시 열기.

  - Claude 키: Cloudflare Secret `ANTHROPIC_API_KEY` (홍중이 등록). 모델 기본 `claude-opus-5-5`, effort `low`.
  - 하루 횟수(한국 시간): 코드 없음 IP당 3 / 코드당 10 / 관리자 1000 / 모두 합쳐 300, 날씨 IP당 60.

  - 남은 약점: KV는 '읽고 1 더하기'가 한 번에 안 돼서 여러 IP가 정확히 동시에 보내면 조금 넘을 수 있음 → 전체 300번이 상한. 완전히 막으려면 Durable Object 필요.

  → 날씨 → 추천 → 그 캠핑의 `items`로 저장 + `ai{advice, days, missing, why, fp, cond, plan}` (동기화됨, 서버가 크기 제한해서 보관)
- 캠핑 화면: 날씨 카드·조언·'없음(대여·대체)' 목록, 장비마다 AI가 고른 이유, '조건 바꿔 다시 추천받기'. 지난 캠핑은 추천 안 됨.
- 디자인은 지금 짙은 초록+주황. 나중에 Higgsfield로 꾸밀 예정(홍중).

## 7단계 메모
- 서버: `worker/pack-push.js` (외부 패키지 없이 WebCrypto로 VAPID 서명 + RFC 8291 암호화). `worker.js`의 `scheduled`가 매일 09:00 KST에 `pushDaily` (처음엔 07:00, 홍중 요청으로 변경).
  - `{pack:{op:'push_sub'|'push_unsub'|'push_test'}}`, KV `push:<코드>` = 기기 최대 5대, 오늘 보냄 표시 `pd:<날짜>:<코드>`
  - 알림 주소는 브라우저 푸시 서버만 허용(구글·모질라·애플·윈도우) — 다른 주소로 요청을 보내는 데 쓰이지 않게
  - 브라우저가 알림을 끈 기기(404·410)는 자동으로 목록에서 뺌
  - 보내는 조건: 오늘 출발하는 캠핑 중 안 챙긴 장비가 있거나 아직 장비를 안 고른 것. 다 챙겼으면 안 보냄.
- 크론: `.github/workflows/worker-deploy.yml`이 wrangler.toml에 `[triggers] crons`를 넣음(지금 있는 크론 + '0 0 * * *', 예전 '0 22 * * *'는 지움).
- 키: 비밀 키는 Cloudflare Secret `VAPID_PRIVATE_JWK`(홍중이 등록), 공개 키는 `pack/push.js`의 `PUSH_PUBLIC_KEY`. 둘은 한 쌍이라 바꾸면 같이 바꿔야 하고, 바꾸면 기존 기기는 알림을 다시 켜야 함.
- 화면: `pack/push.js` 캠핑 목록의 알림 카드(켜기·시험 알림·끄기). 아이폰은 홈 화면에 설치한 앱에서만(iOS 16.4+). 알림을 누르면 그 캠핑 체크리스트로.
